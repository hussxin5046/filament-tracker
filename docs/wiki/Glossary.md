# Glossary

Words used in Wrkbench and in this wiki, in alphabetical order.

| Term | Meaning |
| --- | --- |
| **Access code** | An 8-character code shown on a Bambu Lab printer's screen. The bridge uses it to read the printer. See [Connecting printers](Connecting-printers.md#before-you-start) |
| **Activity** | The record of every change made in a workspace, with who made it and when. See [Dashboard and reports](Dashboard-and-reports.md#activity) |
| **AMS** | Bambu Lab's Automatic Material System: a unit holding several spools that feeds a printer. In Wrkbench each AMS is a piece of attached hardware. See [AMS and spools](AMS-and-spools.md) |
| **Attached hardware** | Anything fitted to a machine, such as a filament feeder, tool changer, dryer or rotary module. It can have slots. See [Machines](Machines.md#attached-hardware-and-slots) |
| **Bridge** | A small program that runs on a computer in your workshop, reads your printers on the local network, and reports to Wrkbench. See [Bridge reference](Bridge-reference.md) |
| **Catalogue** | The list of real machines and materials built into Wrkbench, which you can add in one step. See [Catalogue and settings](Catalogue-and-settings.md#the-built-in-catalogue) |
| **Category** | A kind of thing you stock, such as filament or endmills. It decides which details are recorded for its items. See [Catalogue and settings](Catalogue-and-settings.md#categories) |
| **Custom field** | A detail recorded for every item in a category, such as colour or diameter |
| **Daily report** | The plan for the day shown the first time you open a workspace each day. See [Dashboard and reports](Dashboard-and-reports.md#daily-report) |
| **Guest** | A temporary account for trying Wrkbench without registering. Deleted after 7 days unless turned into a real account |
| **Item** | One thing you stock, with a quantity. For example "PLA Basic, black, 1 kg spool" |
| **Job** | A piece of work run on a machine. Finishing it takes its materials from stock. See [Jobs and the queue](Jobs-and-queue.md) |
| **Job request** | A job asked for by someone outside the workshop through a link. See [Job requests](Job-requests.md) |
| **Label** | A printed QR code for an item or a location. Scanning it opens that item or location. See [Labels and scanning](Labels-and-scanning.md) |
| **Location** | Where something is kept: a room, shelf, drawer or bin. See [Locations](Locations.md) |
| **Low stock** | An item below its minimum stock level. It joins the reorder list |
| **Machine focus** | Narrowing Wrkbench to one machine with the **Whole workshop** button. See [Getting started](Getting-started.md#whole-workshop-or-one-machine) |
| **Machine type** | A group of similar machines. Maintenance set on a type covers every machine of that type |
| **On the move** | A spool taken out at a location display and not yet put away or loaded into a machine. See [Location displays](Location-displays.md#on-the-move) |
| **Offcut** | A usable leftover piece, such as half a sheet. Also called a remnant. See [Inventory](Inventory.md#offcuts) |
| **Passkey** | A way to sign in with your fingerprint, face or screen lock instead of a password. It is kept by your device and only works on your copy of Wrkbench. See [Getting started](Getting-started.md#passkeys) |
| **Project** | A piece of work made up of several jobs, usually for one customer. It adds up their cost and shows the profit, or a recommended price. See [Jobs and the queue](Jobs-and-queue.md#projects) |
| **Queue** | The order each machine will run its open jobs in. See [Jobs and the queue](Jobs-and-queue.md#the-queue) |
| **Recommended price** | The price for a project that would leave your target margin as profit. Shown until you enter the price you invoiced |
| **Role** | What a member may change: owner, admin, operator or viewer. See [Members and roles](Members-and-roles.md) |
| **Slot** | A place in attached hardware that holds one item, such as one spool position in a feeder |
| **Spool tag** | An NFC sticker on a spool, written in the open OpenSpool format, that opens the spool when tapped. See [Spool tags](Spool-tags.md) |
| **Tagged spool** | A spool with an RFID tag the printer can read, such as Bambu Lab's own spools |
| **Target margin** | The share of a project's price you want left as profit, as a percentage. Set for the workspace and, if needed, for one project |
| **Template** | A starting set of categories, machine types and schedules for a new workspace |
| **Tool life** | How many hours of use a tool is expected to last. Wrkbench flags it as worn when it gets there. See [Inventory](Inventory.md#tool-life) |
| **Workspace** | One workshop: its stock, machines, jobs and members. You can belong to several |
