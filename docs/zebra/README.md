# Zebra DataWedge profile

`dwprofile_wrkbench.db` is a DataWedge profile exported from a Zebra TC56 (Android 8.1, DataWedge on firmware
02-13-15.00-OG-U08) on which Wrkbench's handheld mode was tested. It is DataWedge's own export, not edited by hand.

What it sets, for Chrome only (associated app `com.android.chrome`, all activities):

- Barcode input on, internal imager, scanner selection Auto.
- Keystroke output on; Basic data formatting with Send data and Send ENTER key on, Send TAB off.
- Intent output and IP output off; Advanced data formatting off.

It holds no addresses, keys or other personal data: besides the settings, only the device model and firmware
build it was exported from, and when. How to import it is in the wiki: docs/wiki/Labels-and-scanning.md.
